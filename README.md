# Motion_Model — low-poly Thai ghost assets for Unity

Animated, low-poly Thai ghost 3D characters for a horror game in
Unity, built entirely on free tooling because buying animated horror
assets is the expensive path we're avoiding.

## Status

**v0.4 — AI-generated ghost (2026-10-28).** After the friend's
feedback on model quality, the Ghost Woman is now **generated by
local AI** (Hunyuan3D-2mini on this machine's RTX 5060) from their
reference image, then decimated, auto-skinned to a 15-bone rig
(with real legs + walk gait) and projection-textured in Blender.
Krasue stays script-built (v0.2). The one-time toolchain lives in
`tools/` (gitignored); the pipeline scripts are versioned in
`src/hunyuan3d/`.

| Asset | Tris | Bones | Clips | Texture |
|---|---|---|---|---|
| Ghost_Woman.fbx (AI) | 7999 | 15 | Idle, Walk, Attack | 1024 bake, embedded |
| Krasue.fbx (script) | 4028 | 6 | Float, Lunge, Scream | 3 atlas PNGs, embedded |

Previews: `tools/hunyuan3d/out/rig_*.png` (local), legacy procedural
versions tagged `v0.1`–`v0.3`.

## The pipeline in one line

Reference → Blender (model, ≤15k tris, 512px atlas) → Mixamo (free
auto-rig + stock horror animations) → Cascadeur / FreeMoCap (custom
motion) → FBX → Unity (Humanoid / Mecanim) → packaged release.
