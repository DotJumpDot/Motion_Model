## The plan (v2 — indie scope, script-driven, written 2026-10-27)

The big change from v1: **the models are generated by Python scripts
that run headless Blender** (`src/blender/`). The scripts are the
source of truth, the FBX files are build output that we also commit
for convenience. Rigs and animations are hand-keyed inside the
scripts — intentionally stiff and twitchy, which reads as horror, not
as a bug.

## Ghost shortlist — what we're building

| Ghost | Look | Why it's cheap |
|---|---|---|
| **Ghost Woman** (Mae Nak style, v0.1) | Full body, long sinh-style dress, hair curtain covering the face, red eyes peeking | No leg bones (skirt hides legs), no face modeling (hair covers it), ~11 bones. The hair-covered face IS the horror — and it's the cheapest possible face. |
| **Krasue** (v0.2) | Floating head + trailing glowing entrails | No limbs at all, ~7 bones, organ tubes are simple curves. The signature Thai horror asset. |
| Pret (tall gaunt ghost) | deferred | Third character, only if v0.1+v0.2 land well. |

## Budget

0 THB. Blender (GPL, free) is the only tool. Everything else was
dropped with the v2 scope.

## Risks

| Risk | Mitigation |
|---|---|
| Script-generated meshes look too crude | Low-poly + flat pale materials + dark scene is the intended look; iterate profiles in the script if friend says it's off |
| Hand-keyed clips look robotic | Ghost movement *should* look wrong; jitter and snap are tuned in as features |
| Unity import surprises (scale, clips missing) | `IMPORT_CHECKLIST.md` + Blender round-trip verification with real numbers |
| Binary assets bloat repo | FBX at our poly counts is tens of KB; LFS deferred until any asset >1 MB (decision in ARCHITECTURE) |
| Free-tier terms shift under us | N/A now — no free-tier services in the pipeline |
